# SUPERTRUNFO.C
E um game de supertrunfo sobre estados do brasil , todo feito em linguagem de programação C , aonde voce coloca as quantidadedes de cartas e jogadores podendo colocar ate 32 cartas , voce oferece os dados ao sistema e ele te diz quem ganhou o jogo
# Super Trunfo - Países 🌍

Jogo em linguagem C desenvolvido como parte de um projeto acadêmico.  
Cada carta representa uma cidade com dados de população, área, PIB e pontos turísticos.

## Funcionalidades
- Cadastro de cartas (cidades)
- Cálculo de densidade populacional
- Cálculo de PIB per capita
- Exibição dos dados formatados

## Como compilar e executar
```bash
gcc supertrunfo.c -o supertrunfo
./supertrunfo
